# 02 按编号清理（读完审计报告、决定删哪些之后跑）

> 用法：在同一个会话里接着 01 贴；或新会话里先让 Agent 读当天的 `reports/<日期>-audit.md`。
> 把下面「我批准的编号」改成你的选择再贴。删除不进回收站，批准 2 档前先确认有备份。

---

我批准的编号：<例如 1, 4, 7；Downloads 只删 .dmg 和 .ipsw>

请只处理上面点名的对象，规则如下：

1. 只删被点名的，不扩大到父目录、同级目录或「类似的东西」。没点名的一律保留，即使同一档。
2. 回复里有含糊的行，只针对那几行再问我，其余照常执行。
3. 执行中发现报告里没有的新对象，先停下问我。
4. 优先用工具自带命令，少用 `rm -rf`：
   - `git worktree remove <路径>` 后 `git worktree prune`；命令拒绝（有修改或未跟踪文件）就停下报告，不加 `--force`
   - `npm cache clean --force`、`pnpm store prune`、`uv cache clean`、`brew cleanup -s`
   - `ollama rm <模型>`、`xcrun simctl runtime delete <UUID>`（不要手删 runtime 目录）
   - `docker system prune -a` 先单独问我；`--volumes` 必须我明确说「卷也删」才加
5. 动虚拟机磁盘或数据目录前，确认对应应用没在运行。
6. 需要 sudo 的，给我一条可直接运行的命令，我自己跑。不要绕过权限，不要关系统保护。
7. 永不删除：源码、git 历史、`.env` 和配置、密钥与钥匙串、SSH/GPG 密钥、照片和邮件库、云同步目录、`~/.hermes` `~/.codex` `~/.claude`、系统更新快照、备份目标。
8. 每做完一项，打印当前可用空间。异步操作（模拟器删除、虚拟磁盘压缩）确认完成后再报数。

结束时：
- 开始/结束可用空间，实际回收量；每项预计释放与实际释放分开列。
- 哪些项目要重新 `npm install` / 重建 `.venv`，哪些应用下次打开会是空的。
- 把这段总结追加到当天的 `reports/<日期>-audit.md` 末尾。
- 最后运行一次 `~/.disk-guard/scripts/scan.sh`，刷新基线。
